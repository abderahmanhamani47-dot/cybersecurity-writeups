# Root-Me - TCP La roue romaine (ROT13)

## Challenge

This challenge requires connecting to a TCP server and decoding a string encoded using the ROT13 cipher.

A valid response must be sent within two seconds after receiving the encoded message.

## Objective

Automate the reception, decoding, and response process using Python.

## Concepts Learned

- TCP sockets
- ROT13 cipher
- String manipulation
- Python automation
- Network communication

## Technologies Used

- Python 3
- socket
- codecs

## Workflow

```text
Connect to server
    |
    v
Receive ROT13 encoded text
    |
    v
Decode ROT13 message
    |
    v
Send decoded text
    |
    v
Receive flag
```
