# Root-Me - TCP Retour au collège

## Challenge

This challenge requires connecting to a TCP server and solving a mathematical operation within a limited time.

The server provides two numbers:
- Calculate the square root of the first number.
- Multiply the result by the second number.
- Round the final value to two decimal places.
- Send the answer back within 2 seconds.

## Objective

Automate the entire process using Python.
