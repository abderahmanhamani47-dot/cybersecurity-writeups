# Root-Me - ELF x86 - 0 protection

## Challenge

The objective of this challenge is to recover the password required to validate the challenge by analyzing an ELF executable.

## Objective

Analyze the binary and understand how the password verification works in order to retrieve the correct password.

## Concepts Learned

- ELF executables
- Reverse engineering
- Static analysis
- Binary inspection
- Password verification mechanisms

## Tools Used

- Linux
- strings
- file
- Ghidra
- objdump

## Workflow

```text
Obtain ELF binary
    |
    v
Inspect file information
    |
    v
Extract readable strings
    |
    v
Analyze password verification logic
    |
    v
Recover password
    |
    v
Validate challenge
```
